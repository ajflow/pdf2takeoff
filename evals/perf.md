# Performance results

Method follows the open-pdf-studio discipline (format borrowed — their docs
are LGPL): state the scope, keep the discarded runs, tie every number to a
method. Generated by `npm run eval:perf` → `artifacts/perf-results.json`
(counts are deterministic and baseline-gated via `compare.mjs`; **millisecond
figures are informational, machine-dependent, and never CI-gated**).

## Scope

- **Harness:** in-process Node (`evals/bench-perf.mjs`) driving the same
  engine + raster adapters the CLI and MCP server use. No browser, no
  network. Median of 3–5 repetitions after one warm-up call.
- **Inputs:** the bundled samples (`sample-floor-plan.pdf` 2 sheets + rev B),
  a 12-sheet soak PDF (`make-soak.mjs --pages 12 --seed 7`, regenerated
  on demand), and the analytic room sheet (`make-room-sheet.mjs`).
- **Machine:** Apple Silicon dev machine, Node 22.23.1, render scale 3 px/pt.
  CI runs the same harness for the *counts* only.

## Numbers (Node harness, this run)

| operation | median | deterministic count (gated) |
|---|---|---|
| Render page → raster | 12.5 ms/page (max 19.2 over 12 sheets) | 12 pages |
| Tier-1 CV scan, whole sheet | 43.6 ms | 8 hits (sample, known truth) |
| Dynamic Fill, per room | 45.9 ms | 6/6 rooms filled |
| Revision compare, 2 sheets | 75.5 ms | 2 sheets compared, 2 changed |
| Annotation round-trip (write 7 markups + read back) | 3 ms | 7 markups back |

## Numbers (browser, production)

ships — the 76 MB v1 model predates the tiling contract.

  (production callers all use `Map`). Fixed; earlier timings from the same
  run were discarded and re-measured.
- 2026-10-19, cold-slate rehearsal: `make-room-sheet.mjs` failed because
  `evals/artifacts/` did not exist on a clean checkout (it had only ever

  from that run.

## Reading

At 3 px/pt on A4, the whole interactive hot path (render → scan → fill →
annotate) stays under ~130 ms per sheet in Node, which is the budget the
browser app relies on for click-to-teach counting. The expensive step
remains the tier-2 model, and its cost is dominated by the one-off 76 MB
download rather than inference — quantization (roadmap) attacks both.
