Takeoff without uploading your drawings

You can do a construction takeoff without uploading your drawings with pdf2takeoff: it runs in your browser and processes every PDF, scan and DXF on your own computer, so the files never leave your machine. There is no account, the app sends no telemetry, and once the page has loaded it keeps working offline.

How to take off without uploading

  1. Load pdf2takeoff. Open pdf2takeoff.com in any modern browser. There is nothing to sign up for or install.
  2. Open the drawing from your disk. Choose or drop a PDF, image or DXF. The browser reads it locally; it is not sent to any server.
  3. Take off. Set the scale, then measure, count and compare. All of the processing happens in the browser tab on your computer.
  4. Export to your own disk. Download Excel, CSV or the annotated PDF, or print the quantity report. Files are written straight to your computer.

What happens to my drawing?

pdf2takeoff is a static website with no backend: there is no server-side processing to send a drawing to. The PDF is rendered by PDF.js inside your browser tab, measuring, scanning and comparing run in the same tab, and exports download straight to your disk. Your markups and calibrations autosave in your browser's own storage, keyed by the file's fingerprint, so a refresh brings the takeoff back; the drawing itself is never stored. Live sessions share a takeoff between tabs and windows on the same computer, not over the internet.

Does it download anything?

A few features fetch code or data the first time you use them, then cache it. These are downloads to your computer, not uploads of your drawing: the OCR language pack for Auto-read (about 4 MB) and, for the ML symbol detector, the ONNX runtime (about 4 MB) and the model itself (about 76 MB, from GitHub). The HEIC decoder loads only when you open an iPhone photo. Offline, Scan falls back to its computer-vision pass if the model is not cached, and Auto-read needs its language pack, so use it once while online.

Is there any exception?

One, and you have to ask for it. The optional AI count sends one rendered page image to the AI model provider you choose (OpenRouter, OpenAI, Gemini or Z.ai), with your own key, and only when you run it. It is available from the command line today. Point it at a local model through Ollama or LM Studio and nothing leaves the machine at all. If you connect an AI agent to the pdf2takeoff MCP server, the server runs locally, but the agent sends what it reads, such as page images, to its own model provider, as any agent does.

How is this different from cloud takeoff tools?

Many takeoff tools are cloud services: you upload the plan set to the vendor's servers to work on it. That suits some teams, but it puts the drawings outside your control, and some tender documents come with confidentiality terms that make uploading awkward. With pdf2takeoff no third party ever holds the files: they stay where they are. The code is open source under Apache-2.0, so your IT team can read exactly what it does, or host its own copy on an internal web server.

FAQ

Are my drawings uploaded anywhere?

No. pdf2takeoff runs in your browser and processes the PDF on your computer. It works offline once loaded. The only exception is the optional AI count, which sends a page image to the model provider you choose, and only when you ask it to.

Does pdf2takeoff work offline?

Yes, once the page has loaded. Auto-read and the ML detector download their data the first time you use them, so use them once while online if you plan to work offline.

Do I need an account?

No. There is no sign-up, no login and no paid tier.

Is there tracking or telemetry?

The app has none: it never reports what you open, measure or export. The website counts page visits with Cloudflare Web Analytics, which uses no cookies and never sees your drawings.

Can we host pdf2takeoff ourselves?

Yes. It is open source (Apache-2.0) and builds to a static site that any web server can host, including one inside your own network.

Is it suitable for confidential tender drawings?

Yes. The drawings never leave your computer and no third party holds them, so it suits confidential tender documents.
